# Tajawal Font Files

This directory should contain the Tajawal font files for offline use.

## Required Font Files

Please download the following font files from Google Fonts and place them in this directory:

1. **Tajawal-Regular** (400)
   - Tajawal-Regular.eot
   - Tajawal-Regular.woff2
   - Tajawal-Regular.woff
   - Tajawal-Regular.ttf

2. **Tajawal-Medium** (500)
   - Tajawal-Medium.eot
   - Tajawal-Medium.woff2
   - Tajawal-Medium.woff
   - Tajawal-Medium.ttf

3. **Tajawal-Bold** (700)
   - Tajawal-Bold.eot
   - Tajawal-Bold.woff2
   - Tajawal-Bold.woff
   - Tajawal-Bold.ttf

4. **Tajawal-ExtraBold** (800)
   - Tajawal-ExtraBold.eot
   - Tajawal-ExtraBold.woff2
   - Tajawal-ExtraBold.woff
   - Tajawal-ExtraBold.ttf

5. **Tajawal-Black** (900)
   - Tajawal-Black.eot
   - Tajawal-Black.woff2
   - Tajawal-Black.woff
   - Tajawal-Black.ttf

## Download Instructions

### Option 1: Using Google Fonts Helper
1. Visit: https://google-webfonts-helper.herokuapp.com/fonts/tajawal
2. Select all weights (400, 500, 700, 800, 900)
3. Select all formats (eot, woff2, woff, ttf)
4. Download and extract the files
5. Place all files in this directory

### Option 2: Direct Download from Google Fonts
1. Visit: https://fonts.google.com/specimen/Tajawal
2. Click "Download family"
3. Extract the zip file
4. Copy the font files from the extracted folder to this directory
5. Rename files to match the naming convention above

### Option 3: Using Command Line (if you have wget/curl)
```bash
# Download from Google Fonts CDN
# Note: You may need to convert formats or use a tool like google-webfonts-helper
```

## Notes
- The CSS file `tajawal.css` is already configured to use these font files
- The font will automatically apply to all Arabic text (dir="rtl" or lang="ar") in the admin panel
- Font files are loaded offline, so no internet connection is required
